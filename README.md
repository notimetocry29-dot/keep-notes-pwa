# KeepLite - تطبيق ملاحظات شبيه بجوجل كيب (PWA)

تطبيق ويب خفيف وسريع متوافق مع الموبايل (أندرويد PWA) لتدوين الملاحظات بأسلوب Google Keep، مع بحث فوري، ألوان، تثبيت الملاحظات، وضع ليلي، ونسخ احتياطي تلقائي إلى ملف نصي `.txt`.

## المميزات
- واجهة عربية (RTL) متجاوبة مع الموبايل مع دعم الكتابة التلقائية بالعربية والإنجليزية (`dir="auto"`).
- 10 ألوان لملاحظاتك (مثل Google Keep) + بحث فوري + تصفية حسب اللون.
- تثبيت الملاحظات المهمة في الأعلى + عرض شبكي (عمودين) أو قائمة + الوضع الليلي.
- حفظ محلي فوري بدون إنترنت (`IndexedDB` + `localStorage` + `OPFS` + Service Worker).
- **نسخ احتياطي تلقائي في ملف `.txt`**:
  - على متصفح الموبايل (Android Chrome): عند الضغط على **حفظ** بعد أي تعديل أو إضافة أو حذف، يتم تحديث وتنزيل ملف `keep-notes-backup.txt` تلقائياً إلى مجلد التنزيلات (`Downloads`)، مع إمكانية مشاركته أو استعادته في أي وقت.
  - على المتصفحات الداعمة لـ File System Access API (مثل Chrome على الكمبيوتر): يمكنك ربط ملف `.txt` واحد ليتم التحديث فوقه بصمت.

## كيفية التشغيل على الموبايل (أندرويد)
لتثبيت التطبيق كتطبيق موبايل مستقل (PWA) يعمل بدون إنترنت:
1. ارفع محتويات مجلد `keep-notes-pwa` على أي استضافة مجانية تدعم HTTPS مثل **GitHub Pages** أو **Netlify Drop** أو **Cloudflare Pages**.
2. افتح الرابط من متصفح **Chrome** على هاتفك الأندرويد.
3. اضغط على زر **تثبيت** أو من قائمة Chrome اختر **الإضافة إلى الشاشة الرئيسية / Install app**.

## للتجربة محلياً على الكمبيوتر
شغّل السيرفر المحلي عبر PowerShell:
```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```
ثم افتح `http://localhost:8080` في المتصفح.
