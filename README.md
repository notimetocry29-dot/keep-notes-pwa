# مفكرة — KeepLite

**افتح التطبيق:** https://notimetocry29-dot.github.io/keep-notes-pwa/

تطبيق ملاحظات خفيف وسريع للموبايل (PWA + غلاف أندرويد)، مبني بنفس نظام التصميم الثنائي **الليل (Iron)** و**الصباح (Morning)** مع انتقالات سلسة، خطوط محلية، أصوات لمس خفيفة، ونسخ احتياطي تلقائي إلى ملف نصي `.txt`.

## المميزات
- **ثيم Iron (الليل) و Morning (الصباح)**: ألوان دافئة متناسقة، وتطبيق الثيم قبل الرسم (`theme.js`) لمنع أي وميض عند الفتح.
- **حركة سلسة (Buttery UI)**: شاشة بداية بعد ساعتين غياب (`splash.js`)، حوار تأكيد وقوائم سفلية بنفس الثيم (`#ask` و `#xp`)، وتنبيهات قابلة للسحب (`#toast` و `#undo`).
- **أوفلاين بالكامل**: حفظ فوري في `IndexedDB` + `localStorage` + `OPFS` مع `Service Worker` (`sw.js`) وتحديث يدوي آمن بزر «تحديث جاهز».
- **النسخ الاحتياطي التلقائي `.txt`**:
  - عبر غلاف الأندرويد (`android/`): ربط ملف `.txt` دائم عبر SAF للكتابة الصامتة في الخلفية (أو على Drive).
  - عبر متصفح الموبايل: تنزيل/تحديث ملف `keep-notes-backup.txt` تلقائياً عند الحفظ، أو ربط ملف مباشر على المتصفحات الداعمة لـ File System Access API.
- **أمان واختبارات**: سياسة CSP صارمة، تعقيم المدخلات عند الاستيراد، واختبارات تلقائية في `tests/` و GitHub Actions.
